# 編集指示の要点

使用：Built-in ImageGen、4回の編集、transparent_background=true。

共通：1024×1536の縦キャンバス、指示上の起点(512,768)。中央の暗い裂け目と紫の柔らかい縁を残す。実際の透過alpha。宇宙背景、星・銀河、円形記号、ルーン、文字、人物、破片を除去。描かれた黒背景やチェッカーを作らない。

小亀裂：image-gen-1を編集。細い縦の裂け目、左上から右下へ短い枝、控えめな紫の縁。
中亀裂：編集済み小亀裂を第一参照、元image-gen-3を強度参考。同じ縦の主傷と斜め枝を広げ、少数の接続枝を追加。
大亀裂：編集済み中亀裂を第一参照、元image-gen-2を強度参考。主傷の向きを保ちながら中央の暗い破綻を大きくし、広範囲へ接続枝を伸ばす。円や爆発にしない。
渦：編集済み大亀裂を第一参照、元image-gen-4を奥行き参考。角張った裂け目の奥が暗い非対称の渦へ変わる。滑らかな円形ポータルや装飾リングにしない。

生成で画素レベルの一致は保証されないため、傷の登録起点・Crossfadeの成長感は実装時の検証対象。
