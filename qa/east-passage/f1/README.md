## Observations and raw failures

`observe-fixed.cjs` is an identical Node-side preloader in both native-fixture runs. It delegates the stock Playwright launch, tap, waitForFunction and reload operations. After the fixture's own playback predicate succeeds, it records `playing`, `paused` and exact positive `currentTime` before reload. This adds an equal read-only measurement point, not an alternative input or successful-playback surrogate. No HTML, Audio, page-native method or game response replacement is added by the preloader. The fixture's existing observer still delegates to the native media methods. The observer worker synchronously rewrites its JSON at milestones and reload timeout, so even a stalled teardown retains evidence.

Artifacts contain `native-fixed.tap.log` and its raw process exit; the original Node test remains **FAIL** on the old engine. Only this exact sequence may produce `EXPECTED_OLD_ENGINE_STALL`: successful real button tap → successful positive-time unpaused playback → reload → pagehide → pause-enter → the fixture's exact `page.reload`/DOMContentLoaded 45000ms TimeoutError, no pause-return/new-document, no pageerror/crash. The evidence gate accepting this signature does **not** mean an ordinary old-browser test passed. A generic failure, wrong timeout/API, tap failure, launch failure, playback failure, crash, or a document that actually committed is `INCONCLUSIVE_FAILURE`. If the old fixture passes, it is `NOT_REPRODUCED` and the requested reproduction gate is not green.

New engine requires raw native PASS, pause-return and a replacement document, plus the unwrapped four and unchanged existing eleven all passing. Classifier adversarial tests reject false reproductions. Exact timeout stack, full lifecycle trace, version/build, input hashes, baseline/execute HEAD and Actions URL accompany results. The existing 45s fixture timeout and all asserts remain unchanged.

## Run and retrieve

Use an empty disposable checkout of the dedicated QA branch. Keep the inherited proxy/CA settings. On a machine with normal Playwright dependencies:

```sh
npm install --no-save --no-package-lock playwright@1.56.1
npx playwright install --with-deps webkit
F1_EVIDENCE_DIR=/tmp/f1-old node qa/east-passage/f1/run.cjs old

npm install --no-save --no-package-lock playwright@1.64.1
npx playwright install --with-deps webkit
F1_EVIDENCE_DIR=/tmp/f1-new node qa/east-passage/f1/run.cjs new
node qa/east-passage/f1/compare.cjs /tmp
```

For the pair command, preferably place only the two run directories under a dedicated evidence parent (the comparator requires exactly two `result.json` files). Actions executes these as separate fresh runner jobs; it never swaps versions during a job. `.github/workflows/webkit-f1-evidence.yml` uploads `f1-old-<run>-<attempt>`, `f1-new-<run>-<attempt>` and `f1-paired-<run>-<attempt>`. Failure artifacts upload with `always()`. The ordinary eleven-test workflow is untouched; the new-engine evidence job also executes those same two test files normally, without the F1 preloader.

## Limits

Only synthetic intercepted HTTPS is tested here. No local HTTP evidence or claim is retained. No production/preview save or origin is touched. The init-script/native wrappers in the minimal probe remain an observation condition; the four game scenarios are separately run without them to expose observer-induced differences. This does not prove a specific C++ lock, all engines between the pins, physical iPhone behavior, audio audibility or release safety. Prior device PASS is not transferred. Publish run URLs, exact HEAD and artifact IDs in the new Draft PR; no protected PR is edited.
